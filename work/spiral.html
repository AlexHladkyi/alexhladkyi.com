Spiral Task Manager

Designed the v1.0 mobile app for Spiral, a Basecamp-inspired task manager tailored for event organizers and on-site production teams.

Serving as the UX/UI designer from discovery to interactive prototyping, I structured a multi-event dashboard that provides coordinators with a bird's-eye view of task progress and automated problem alerts.

To streamline operations, I designed a decentralized communication system featuring contextual task-based chats and a cross-team request framework that empowers field staff to address issues directly without interrupting coordinators.
