Zyda Dashboard

For Zyda I worked on UX/UI updates for the merchant configuration portal of a food order processing service that tackled the complexity of real-time dual-language management by designing a parallel English/Arabic layout for the menu setup module.

This update eliminated toggle friction for administrators, creating a significantly less error-prone onboarding and menu-building workflow.

My role

User experience (UX), User flows, User interface (UI)

Zyda is a digital ordering and customer engagement SaaS for restaurants, cafes and fast food businesses.
